# 五组手算验收

单位均为 USD；单价来自 `prices/2026-09-24.json`。以下均为**合成请求**，额外工具费显式为 0。设 I=含缓存输入总量、C=缓存读、W=缓存写、O=含 reasoning 输出总量、R=reasoning 子集：

`普通输入 = I − C − W`

`账单 = [(I−C−W)×输入价 + C×读价 + W×写价 + (O−R)×输出价 + R×reasoning价] / 1000000 + 工具费`

reasoning 采用输出费率，拆项仅为审计，不额外加到 O 上。失败尝试仍收费；重试每条只计一次。

1. **缓存读写 + reasoning（Sol）**：I=10000，C=6000，W=2000，O=1000，R=400。普通输入 2000。
   `2000×2/1e6 + 6000×0.2/1e6 + 2000×2.5/1e6 + 600×10/1e6 + 400×10/1e6`
   `= 0.004 + 0.0012 + 0.005 + 0.006 + 0.004 = 0.0202`。
2. **失败后重试（Sol）**：两次都采用例 1 用量，一次 failed，一次 retry=true。每项为 `0.008 + 0.0024 + 0.010 + 0.012 + 0.008 = 0.0404`；不能只计最终成功的 0.0202，也不能把 retry 行再翻倍。
3. **Opus Standard / Fast 双倍（5m 写入）**：例 1 用量，Standard 各项 `0.008 + 0.0012 + 0.010 + 0.012 + 0.008 = 0.0392`。Fast 各项 `0.016 + 0.0024 + 0.020 + 0.024 + 0.016 = 0.0784`，含缓存读写均恰好两倍。
4. **Sol 长上下文**：I=300000，C=200000，W=50000，O=10000，R=4000。因 I>272000，**整个请求**使用 input=4、read=0.4、write=5、output=15。
   `50000×4/1e6 + 200000×0.4/1e6 + 50000×5/1e6 + 6000×15/1e6 + 4000×15/1e6`
   `= 0.20 + 0.08 + 0.25 + 0.09 + 0.06 = 0.68`。不是只对超出部分加价。
5. **Opus 1h 写入**：例 1 用量，写价从 5 变为 8，其余不变：`0.008 + 0.0012 + 0.016 + 0.012 + 0.008 = 0.0452`。Sol 同样指定独立 1h 写入时，由于对应官方字段未确认，总额为 unknown。

三轮 CLI 合成轨迹为失败、重试、final，每轮例 1 的 token 量。Sol `3×0.0202=0.0606`；Luna 单轮 `0.0002+0.00006+0.00025+0.0003+0.0002=0.00101`，三轮 `0.00303`；Opus `0.1176`；Fast `0.2352`。无质量证据时三个轮次都保留 Sol，Luna 每轮只作节省 `0.0202−0.00101=0.01919` 的情景；实选策略节省为 0。

`tests/test_cost_router.py` 对以上金额及关键逐项费用使用固定数字断言。`tests/verify_receipts.py` 独立复算 CLI JSON 收据的每轮费用；不导入生产计算器。实跑输出见 `receipts/independent-check.txt`。
